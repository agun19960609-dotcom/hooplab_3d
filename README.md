# HOOPLAB

Traditional Chinese basketball tactics board for coaches. Draw a play, watch it in 3D, share a short clip, and keep custom plays on the device.

There is no login and no cloud sync.

## Run

```bash
git pull
flutter pub get
flutter run
```

Store submission notes, screenshot sizes, and the permission list are in [STORE.md](STORE.md). The in-app privacy policy is `assets/privacy_policy.md`.
